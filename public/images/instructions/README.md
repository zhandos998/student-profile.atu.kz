# Скриншоты для страницы инструкции

Кладите PNG/JPG файлы в эту папку. Страница `/instructions` автоматически покажет файл, если имя совпадает с `image` в `resources/js/Pages/Instructions.jsx`.

Общий постер в начале инструкции должен называться:

- `instruction-cover.png`

Если для одного шага нужно несколько скриншотов, используйте `images`:

```js
images: ['student-card-1.png', 'student-card-2.png'],
```

Старый вариант с одним файлом тоже работает:

```js
image: 'student-card.png',
```
